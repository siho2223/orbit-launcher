# Участие в разработке

Начни с [инструкции по сборке](docs/BUILDING.md) и [архитектуры](docs/ARCHITECTURE.md).

Для сообщения об ошибке укажи версию ORBIT, Windows, Minecraft и загрузчика, действия для воспроизведения и точный текст ошибки. Перед публикацией журналов убери токены, личные пути и данные аккаунтов.

Для изменений: создай ветку, внеси небольшой связный набор правок, проверь сборку и подходящие тесты. В pull request опиши проблему, новое поведение и выполненные проверки. Отдельно укажи, если тест запускал реальную игру или скачивал игровые файлы.

Не добавляй в репозиторий игровые JAR, моды, пользовательские скины, сохранения, настройки аккаунтов, ключи подписи или собранные EXE. Не меняй файлы сторонних компонентов без обновления соответствующих исходников и уведомлений.

Изменения кода ORBIT должны быть доступны на условиях GPL-3.0-only.
