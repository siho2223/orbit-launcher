ORBIT 0.9.1 preview updates the launcher from the public 0.7.1 release with three selectable themes, a Brawl Stars style lobby and modpack ZIP export.

- Home shows the selected instance and its actual Minecraft, loader and Java versions.
- Cards and settings sections appear in sequence. Buttons respond to hover and press without cards expanding outside their bounds.
- Selected instances have a visible outline. Brawl Stars includes draggable skin rotation, emotes and drifting background particles.
- Reduced motion stops the new animations; idle animation pauses when minimized.
- Export ZIP on an instance card packages mods, configs, resource/shader packs and pack scripts, with progress and cancellation. Includes version metadata and recipient instructions. This is a content ZIP; automatic pack import is not included.
- Fixed stale catalog results, transparent skin overlays, same-profile instance selection, theme frame geometry and library filter reset.

Limitations: Microsoft sign-in is not implemented. CurseForge integration is pending API access; catalog search currently uses Modrinth. GTNH gameplay compatibility has not been verified. No Minecraft game files are bundled.

Validation: Release build with zero warnings/errors; 201 automated checks across basic/core, instances, ZIP export, theme/animation regressions, skin rendering and upgrade UI. Offscreen screenshots inspected in all themes. Minecraft gameplay was not launched or verified.
