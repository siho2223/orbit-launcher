# ORBIT 0.10.0 preview

The new default interface adapts XMCL's classic UI to WPF, with an 80px navigation rail, player panel, compact two-column instance list, layered dark surfaces and an offline profile dialog. The previous default 2 option migrates to default. Brawl Stars remains available separately.

Existing launch, Modrinth browsing, skins, ZIP export and per-instance folders remain connected to the new controls. Repeating the version-picker button closes it. Animation completion now restores fully visible controls even when frame delivery is delayed.

XMCL credit and the MIT license are retained in source and the executable. No XMCL brand images or Minecraft panorama textures are bundled. Authentication remains limited to ORBIT's existing offline profile; Microsoft sign-in and CurseForge integration are not included in this update.

Validation: build without warnings/errors; 185 current automated checks including 19 XMCL-specific checks, plus offscreen home/profile/settings/compact/Brawl renders. Minecraft gameplay was not launched.
