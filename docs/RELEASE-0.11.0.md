# ORBIT 0.11.0 preview

Local preview of the Brawl interface migrated to actual Millida CSS, adapted Play/HubTile components and Mine3D via WebView2. Themed settings, library, skins, mods, worlds and logs are connected to ORBIT's native functions; ZIP export remains available on instance cards. Five palettes, drag rotation and emotes are retained.

WebView2 Runtime is required. No Millida proprietary artwork, services, account IDs or unsupported buttons are included. Source attribution and all dependency notices are shipped.

Microsoft protocol code and encrypted storage are implemented and fixture-tested, but real login is unavailable in this preview because ORBIT has no registered client ID. Registration alone does not establish Minecraft Services access; verify that access and perform a real login before enabling it in a release.

See VERIFICATION.md and MICROSOFT-SETUP.md for checks and limits. This preview is local and has not been published to GitHub.
