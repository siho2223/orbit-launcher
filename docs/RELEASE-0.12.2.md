# ORBIT 0.12.2 — version catalog tabs

The version picker now has All versions, Forge and Fabric tabs in Default and Old theme. Loader tabs list supported Minecraft releases from official compatibility metadata, let you select an existing matching loader profile, and install the loader directly for versions that are not installed. Search works within the selected tab. Forge and Fabric retain their respective icons and colors.

The Default version list scrolls within available window height and remains above header controls at minimum window size. Loader metadata loading and retry behavior are preserved.

This local preview includes a Windows x64 installer and full source archives. Quick installation uses official Forge/Fabric loaders; OptiFine is not bundled. Minecraft gameplay was not tested.
