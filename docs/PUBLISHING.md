# Загрузка на GitHub

1. Создай новый **публичный пустой репозиторий** с именем, например, `orbit-launcher`. На этапе создания не добавляй другой README, .gitignore или лицензию.
2. Распакуй подготовленный исходный архив. Загрузи через **Add file → Upload files** содержимое папки ORBIT: `OrbitLauncher.csproj`, `Core`, `Tests`, `Assets`, `ThirdParty`, документы и служебные файлы. Не загружай сам исходный ZIP как единственный файл репозитория.
3. Проверь наличие `LICENSE`, `.gitignore`, `README.md` и двух исключений в ThirdParty: authlib-injector JAR и архив его исходников. Они нужны для сборки и лицензионных уведомлений.
4. Если загрузчик браузера пропустил скрытые файлы `.gitignore`, `.gitattributes`, `.editorconfig` или `.github`, добавь их отдельно. При использовании git они добавляются вместе с остальными исходниками.
5. В описании репозитория можно написать: **Minecraft Java launcher for Windows: local profiles, skins and Modrinth mods, resource packs and shaders. C# / WPF / .NET 8.**
6. Готовую сборку размещай отдельно через **Releases**, как архив результата `scripts/build.ps1 -Publish`, вместе с README и лицензиями. Текущая версия предварительная; это стоит отметить в описании релиза.

Папка с исходниками уже подготовлена. Эта инструкция не выполняет публикацию, не создаёт репозиторий и не загружает данные от твоего имени.
